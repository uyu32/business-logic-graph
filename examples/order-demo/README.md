# 合成订单示例 / Synthetic order example

本示例为开源发布专门编写，不来自真实业务仓库。源码、配置和测试演示订单金额过滤与排队，业务图演示层级、断言、证据和故意保留的库存门禁阻断。

This fictional example was written for the public project. It demonstrates order filtering and queueing, graph hierarchy, evidence, and an intentionally unverified inventory workflow.

`synthetic-order-demo-v1` is illustrative, not a Git commit. Use the graph for read-only validation, context queries, and HTML rendering, not as verified evidence for another repository. BLG rejects mismatched source revisions.
